## 1. 文档说明

本文档根据当前工作区 `test/integration/` 下的源码整理，目标是把“已经存在并正在执行的集成测试”转换成可阅读的测试用例清单。

范围说明：

| 项目 | 说明 |
| --- | --- |
| 统计范围 | `test/integration/*.c` 中的 `RTFS_TEST(...)` 与 `RTFS_TEST_GROUP(...)` |

| 其中 | 30 个功能/语义类集成测试，2 个性能基准场景 |

| 组织方式 | 按“挂载/生命周期、命名空间、文件 I/O、元数据、恢复、错误边界、性能”分组 |
